Assignment name  : title_c
Expected files   : title_c.c
Allowed functions: write
--------------------------------------------------------------------------------

Write a program that takes a string and displays it, capitalizing the first
letter of each word and displaying the rest in lowercase (or keeping the rest
of the characters as they are), followed by a newline.

A "word" is defined as a part of a string delimited by spaces or by the
start/end of the string.

If the number of arguments is not 1, the program displays a newline.

Example:

$> ./title_c "no no no no..." | cat -e
No No No No...$
$> ./title_c "hello world" | cat -e
Hello World$
$> ./title_c | cat -e
$
