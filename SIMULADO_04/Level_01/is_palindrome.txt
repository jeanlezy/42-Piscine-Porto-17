Assignment name : is_palindrome

Expected files : is_palindrome.c

Allowed functions: write

Escreva um programa que receba uma string e determine se ela é um palíndromo (lida da mesma forma da esquerda para a direita e da direita para a esquerda).

Se a string for um palíndromo, o programa deve imprimir a própria string seguida de um '\n'.

Se não for um palíndromo, o programa deve apenas imprimir um '\n'.

Se o número de argumentos for diferente de 1, o programa deve apenas imprimir um '\n'.

Exemplos de Saída:

Bash
$> ./is_palindrome "radar" | cat -e
radar$
$> ./is_palindrome "hello" | cat -e
$
$> ./is_palindrome | cat -e
